
#  🎮 Breakout Game

Este proyecto consiste en una versión del clásico videojuego Breakout, desarrollada como trabajo final de la asignatura Laboratorio Multimedia utilizando HTML, CSS y JavaScript.

## 🖥️ Descripción

El objetivo del juego es controlar una pala para mantener la pelota en movimiento y destruir todos los bloques presentes en cada nivel. El proyecto ha sido desarrollado íntegramente para ejecutarse en el navegador, sin necesidad de instalar software adicional.

## 🕹️ Características
- Pantalla de bienvenida con introducción del nombre del jugador.
- Sistema de clasificación con almacenamiento de las 5 mejores puntuaciones.
- Selección de modo de juego
- Control de la pala mediante teclado.
- Sistema de puntuación.
- Menú de ajustes personalizable
- Interfaz desarrollada con HTML y CSS.
- Lógica completa del juego implementada en JavaScript.

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## 🧩 Instalación y ejecución

1. Clona este repositorio:

```bash
    git clone https://github.com/Marionaaa22/Practica2_LabMultimedia.git
```

2. Accede al directorio del proyecto
3. Abre el archivo index.html en tu navegador.
